Install Klipper Pendant

Install the latest stable firmware on an OpenNextion ONX3248G035.

  1. Use Chrome or Edge on a desktop computer.
  2. Connect the display with a USB data cable.
  3. Click Connect, select the display's USB port, then confirm installation.
Use Chrome or Edge on a desktop computer to install firmware. This installer must be opened over HTTPS.

Warning: first-time installation replaces the factory firmware. Do not disconnect the USB cable while installation is running.

After the display restarts, configure Wi-Fi and Moonraker in Settings. The E-STOP control is a network request, not a hard-wired emergency stop.

Need help or a manual installation method? See the firmware guide.
